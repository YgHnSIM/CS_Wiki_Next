확장 가능한 지식 그래프 UI의 2단계로 모든 공개 지식 문서에 직접 관계 탐색기를 추가했다. 같은 이웃과 근거·학습 순서·관련 항목·본문 언급이 겹칠 때 노드를 중복하지 않고 관계 묶음으로 유지한다. 지도는 편집 관계, 근거, 학습, 관련 항목, 본문 언급이 한 계열을 독점하지 않도록 최대 12개 대표 이웃을 균형 있게 고르고, 렌즈를 바꾸면 해당 관계에서 더 약한 연결도 다시 대표 관계로 드러낸다.

선을 선택하면 두 문서의 방향, 관계 이름과 근거 문맥을 완전한 문장으로 번역한다. 전체 1홉 이웃은 대표 관계별 접이식 목록에 남겨 시각화에 표시되지 않은 문서도 탐색할 수 있게 했다. 선택과 렌즈는 URL에 보존되며 새로 고침과 뒤로 가기에서 복원된다. 방향키·Home·End·Escape 조작, 단일 상태 알림, 자바스크립트 없이도 읽을 수 있는 전체 목록을 제공한다.

앞으로 문서와 관계 수가 늘어나는 상황에 대비해 문서별로 전체 간선을 다시 훑지 않고 한 번 만든 인접 간선 색인을 공유한다. 데스크톱은 12개 노드 의미 배치를 사용하고, 860px 이하에서는 기본적으로 지도를 접으며 최대 6개 노드를 44px 이상의 터치 영역을 가진 전용 좌표계로 다시 그린다. 대표 문서인 [[컴퓨팅 능력이란 무엇인가]]에서는 숨김 운영 문서를 제외한 57개 직접 이웃과 141개 유형 관계를 해석한다.

변경된 페이지와 코드:

- 갱신: [[overview]], [[log]]
- 선택·해설 모델: `site/graph/selectors.mjs`
- 문서 화면: `site/build.mjs`, `site/assets/article-relationships.js`, `site/assets/site.css`
- 자동 검사: `tests/site-graph.test.mjs`

### 검증

- Node 사이트·그래프 테스트 17개 통과
- 대표 문서에서 전체·학습 렌즈, 선택 URL 복원, 키보드 이동과 관계 해설 동기화 확인
- 390×844 화면에서 전용 6노드 지도, 기본 접힘과 가로 넘침 없음 확인
- 전체 정적 사이트 빌드 통과
- `raw/` 원본 변경 없음
