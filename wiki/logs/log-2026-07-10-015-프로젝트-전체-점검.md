`raw/`와 `wiki/` 전체를 대상으로 구조, 프론트매터, 출처 추적성, 내부 링크, 색인, 로그, 내용 정확성을 점검했다. 원본 `raw/`는 수정하지 않았다.

점검 결과:

- 위키 158개 페이지의 필수 프론트매터, 상태값, 유형·상태 태그는 모두 유효했다.
- 위키링크 3,576개에서 깨진 링크, 모호하게 해석되는 현재 링크, 잘못된 섹션 링크, 고아 페이지는 발견되지 않았다.
- 정규 소스 6개가 참조하는 raw 문서 9개는 누락이나 중복 없이 모두 연결되어 있었고, [[index]]는 자기 자신을 제외한 157개 페이지를 모두 수록한다.
- 우선 보완 사항으로 참고 자료 27개의 raw 원본·스냅샷 부재, 내용 정확성 검토가 필요한 계산 가능성·계산기/컴퓨터 구분·Unicode scalar value·초기 소프트웨어 계층화 서술을 확인했다.
- 관련 항목 연결 1,289개 중 308개는 상대 페이지 본문에 역링크가 없고, [[log]]의 반복 H2 제목, [[index]]의 출처 수 표기 7건, 출처 메타데이터와 본문 인용 불일치 4개 페이지도 정리 대상으로 확인했다.
- 모든 페이지가 `active` 상태여서 초안·검토·승인 단계를 구분하지 못하고 있으며, 짧은 인물·개념 페이지는 검토 상태 운영과 추가 근거 보강이 필요하다.
- 외부 출처 URL 65개를 확인한 결과, FORTRAN 매뉴얼의 보조 Bitsavers 미러 1개는 접속되지 않았으나 같은 페이지에 정상적인 Computer History Museum 사본이 함께 등록되어 있다.

권장 우선순위:

1. 참고 자료 provenance 스키마와 raw 보존 원칙 확정
2. 계산 이론·계산기/컴퓨터·Unicode 용어·역사적 계층 서술 교정
3. 자동 lint와 색인·통계 자동 생성 도입
4. 관련 항목 역링크, 로그 제목 계층, 출처 수·별칭·ingest 번호 규칙 정리
5. `draft` → `review` → `active` 검토 상태 운영과 얕은 페이지 보강
