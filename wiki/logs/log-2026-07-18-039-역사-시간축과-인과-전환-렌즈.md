확장 가능한 지식 그래프 UI의 6단계로 컴퓨팅 능력의 발달을 연도순 목록이 아니라 **한계 → 대응 → 새 능력 → 다음 제약**의 이동으로 읽는 역사·인과 렌즈를 추가했다. 출판 연도와 사건 기간을 분리하고 제출·출판, 초판·확인 판본, 관찰 기간의 차이는 `historical_note`에 보존했다. 제목·파일명·위키 작성일에서 연도를 추측하지 않으며, 연도가 없는 문서는 삭제하거나 인접 시대에 끼워 넣지 않고 `연도 미상`에 둔다.

현재 203개 공개 문서 가운데 원전 대조로 시점을 기록한 문서는 28개다. 사건 시점 문서 5개와 출판 시점 문서 23개를 고정된 여덟 연대 구간에 배치하고, 나머지 175개는 아홉 번째 `연도 미상` 구간에 보존했다. 역사 층위는 이론·기계·아키텍처·소프트웨어·시스템·서비스·측정과 미분류 레인으로, 컴퓨팅 능력은 계산 가능성·복잡도·프로그래밍 가능성·실현 성능·확장성·자원 효율·결과 신뢰성으로 교차 필터링한다.

자동 본문 언급이나 관련 항목·근거·학습 순서는 인과로 해석하지 않는다. 편집자가 근거와 설명을 붙인 `responds_to`, `enables`, `precedes`, `constrains`만 승격해 15개 검토 전환을 만들었으며, 데이터 계약상 완전 전환 9개와 누락된 역할을 그대로 보이는 부분 전환 6개로 나뉜다. 같은 대응 문서의 `responds_to`와 `enables`는 한계·대응·새 능력으로 합성하고, 부분 전환에 관계를 보강해도 전환 ID와 공유 URL을 유지한다. 순서나 제약 관계는 의미상 출발 역할의 시점·위치를 따르는 독립 전환으로 보존한다. 알려진 연대가 관계의 기대 순서와 어긋나도 간선을 바꾸지 않고 충돌 상태와 원래 기록 방향을 남긴다.

첫 화면은 manifest와 시대 개요만 불러오고 조회 버킷과 시대 조각은 선택할 때 지연 로드한다. 아홉 시대는 현재 10개 조각이며 한 조각은 최대 120개 문서와 96개 전환 요약으로 제한한다. 직접 선택은 최대 96레코드인 결정적 조회 버킷 하나를 읽고, 전체 검색은 현재 네 버킷을 제한된 동시성으로 합친다. 고차수 전환은 최대 6개 대표 간선·32KiB 요약과 최대 48레코드·64KiB 상세 쪽으로 분리해 한 쪽씩 불러오고 캐시한다. 시대의 첫 조각과 이후 조각에는 각각 복원 가능한 정적 주소가 있고, 자바스크립트가 없어도 해당 문서 링크·쪽 이동과 대응 문서의 전체 관계 표를 사용할 수 있다. 앞으로 공개 문서가 추가되면 안정 ID에 따라 정확히 한 시대 조각으로 자동 수용되고, 상한을 넘는 시대·조회·상세 데이터에만 새 조각이 생긴다.

변경된 페이지와 코드:

- 역사 연도·층위·능력 메타데이터와 검토 관계: 관련 정규 소스·참고 자료, 개념과 분석 문서
- 운영 규칙: [[지식 그래프 관계 스키마]], [[overview]], [[log]]
- 시대·전환 데이터와 스키마: `site/graph/history.mjs`, `site/graph/schema.mjs`, `site/graph/model.mjs`, `site/catalog.mjs`
- 역사 렌즈 화면·상태·정적 경로: `site/assets/history-state.js`, `site/assets/history-lens.js`, `site/build.mjs`, `site/assets/site.css`
- 자동 검사: `tests/site-history.test.mjs`, `tests/site-history-state.test.mjs`, `tests/site-history-lens.test.mjs`, `tests/site-graph.test.mjs`, `site/verify-build.mjs`

### 검증

- 실제 정적 빌드의 history manifest에서 공개 문서 203개가 여덟 연대 구간 또는 `연도 미상`에 중복 없이 한 번씩 배치됨을 확인
- 사건 시점 5개, 출판 시점 23개, 연도 미상 175개와 검토 전환 15개, 시대 9개·조각 10개를 대조
- 완전 전환 9개·부분 전환 6개, 조회 버킷 4개를 확인하고 현재 15개 전환은 모두 32KiB 안의 인라인 요약이라 상세 조각이 필요하지 않음을 대조
- 문서 120개·전환 요약 96개 조각 상한 아래에서 현재 가장 큰 조각 120개 문서·14개 전환, 안정 ID 기반 위치 색인, 고정 시대 경계와 콘텐츠 지문 적용 확인
- 자동 관계가 인과 전환에 섞이지 않고 네 가지 검토 관계의 설명·근거·기록 방향이 보존되며, 근거가 비면 lint와 빌드가 실패함을 확인
- 역사 데이터·URL·검색·필터·키보드·지연 로드·오류 복구 테스트 51개와 전체 Node 테스트 123개·Python 테스트 14개 통과
- 1,000개 능력 간선 모의 전환에서 6개 대표 간선·32KiB 요약과 48레코드·64KiB 상세 쪽, 쪽별 끝점 문맥, exact-once 역할·간선과 페이지별 캐시를 확인
- 5,000개 문서 모의 데이터에서 시대·조회 조각 증가, 첫 화면 예산, 안정 전환 ID와 단일 요청 상한을 확인
- 207개 위키 페이지 정적 사이트 빌드와 시대별 정적 주소 생성 통과
- 1265×720 실 브라우저에서 전체→시대→사건→전환, 한국어·초성 검색, 층위 필터·초기화와 정적 조각→전체 개요→새로고침·뒤로 가기 복원을 확인했다. EDSAC의 단일 사건 시점은 `1949년`으로 표시되고 Manchester Baby→EDSAC 전환의 외부 근거는 제목과 문서 링크로 열렸으며, 검색 listbox의 12개 option ID는 모두 고유했다. 문서 가로 넘침 0, 오류 패널 숨김, 콘솔 오류·경고 0건을 확인했다.
- 위키 lint: 207개 페이지, 위키링크 5,443개, 오류 0건, 경고 0건
- `raw/` 원본 변경 없음
