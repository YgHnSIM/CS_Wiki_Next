GitHub Actions `Deploy CS Wiki`의 114·115 실행이 빌드 12초 만에 `Validate change set`에서 실패했다. 사이트 빌드와 브라우저 검사는 시작되지 않았다. 수정 커밋 `af57cc8`의 실행 102는 빌드·GitHub Pages 배포에 성공했다.

## 증상

| 실행 | 커밋 | 결과 | 실패한 단계 |
|---|---|---|---|
| [100](https://github.com/YgHnSIM/CS_Wiki/actions/runs/35201469901) | `dc20ff9` 114 온톨로지 층위·계약 | failure | Validate change set |
| [101](https://github.com/YgHnSIM/CS_Wiki/actions/runs/35202307531) | `fbbcf1d` 115 관계 표·학습 경로 | failure | Validate change set |
| [102](https://github.com/YgHnSIM/CS_Wiki/actions/runs/35202853846) | `af57cc8` 116 검토 승격 | success | 없음 |

로컬 `npm run lint:wiki`와 `npm run maintenance:check`는 통과했다. 배포 게이트는 그 두 명령과 다른 규칙을 본다.

## 직접 원인

`scripts/validate_change_set.mjs`는 직전 커밋(`github.event.before`)과 `HEAD` 사이에서 바뀐 `active` 페이지를 검사한다. 이전 버전의 `review.mode`가 `legacy-baseline`이면 현재 버전도 `attested`여야 한다.

114·115는 공개 지식 문서의 층위·관계·본문을 바꿨지만 `review.mode`를 `legacy-baseline`으로 두었다. CI는 예를 들어 `wiki/concepts/시스템 호출.md`에 `review.attestation`을 보고 실패했다. `updated` 날짜는 이미 2026-09-17이라 `updated.required`는 나오지 않았다.

## 기여 원인

1. **로컬에서 변경 집합 검사를 커밋 기준으로 돌리지 않았다.** `BASE_SHA` 없이 실행하면 검사가 건너뛰어지고, 워킹 트리만 있는 상태의 `BASE_SHA=HEAD` 비교는 커밋되지 않은 파일을 보지 못한다. 푸시 전에 `BASE_SHA=$(git rev-parse origin/main) npm run validate:changes`를 커밋 뒤에서 돌려야 한다.
2. **Windows Git 경로 인용.** `scripts/update_wiki_updated.mjs`는 줄바꿈으로 경로를 나눠 `wiki/`로 시작하는 항목만 골랐다. 한글 파일명은 `"wiki/concepts/\354\...md"`처럼 C 인용으로 나와 필터에서 빠졌다. 그래서 첫 승격 시도는 ASCII 경로 19개만 바꿨다. CI의 `validate_change_set.mjs`는 `-z`(NUL 구분)를 쓰므로 한글 경로를 정상적으로 보고 실패했다.

## 해결과정

1. 실패한 job 로그에서 `review.attestation`이 유일한 오류 코드임을 확인했다.
2. `update_wiki_updated.mjs`의 `git diff`에 `-z`를 넣고 경로의 역슬래시를 `/`로 정규화했다.
3. 마지막 성공 배포 `cd5d0c5` 이후 바뀐 공개 위키 페이지 154개를 `review.mode: attested`, `reviewed_at: 2026-09-17`, `reviewed_by: grok`로 올렸다.
4. 커밋 `af57cc8`을 푸시한 뒤, CI가 쓸 `BASE_SHA=fbbcf1d`로 로컬 `validate:changes`가 133개 경로를 통과함을 확인했다.
5. 실행 102는 Validate change set, `npm run check`, Pages 배포까지 성공했다.

## 재발 방지

- 기존 `active` 페이지를 실질 변경하면 `legacy-baseline`을 `attested`로 승격한다. `scripts/update_wiki_updated.mjs`가 이 전환을 수행한다.
- 푸시 전 검사는 커밋 뒤 `BASE_SHA`를 `origin/main`(직전 원격 HEAD)으로 두고 `npm run validate:changes`를 실행한다.
- Git 경로 목록은 `-z` 또는 `core.quotepath=false`를 쓴다. 줄바꿈 분리는 한글 경로를 놓친다.
