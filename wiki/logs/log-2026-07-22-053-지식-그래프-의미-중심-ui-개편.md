전역 force-directed 그래프를 기본 화면에서 내리고, 도메인별 문서 군집과 군집 사이의 교차 연결 수를 먼저 읽을 수 있는 `군집 개요`를 추가했다. 문서를 선택하면 선택 문서를 캔버스 중앙에 두고 모든 직접 이웃을 `계층·학습`, `구현·활용`, `역사·제약`, `근거·연관`의 네 관계 구역에 배치한다. 두 문서를 차례로 선택하면 결정적인 최단 연결 경로만 남기는 `두 문서 경로`도 추가했다.

그래프 설정은 지식 탐색에 필요한 문서 유형 필터, 관계 방향, 레이블 밀도만 남겼다. 태그·첨부·미생성 파일·사용자 그룹·애니메이션·물리 장력 조절 UI를 제거하고 검색과 세 탐색 모드를 상단의 주 동작으로 재구성했다. 연결선을 선택하면 관계 종류와 방향, 편집자가 기록한 관계 설명, 직접 근거 문서를 인스펙터에서 확인할 수 있다. 선택 인스펙터는 데스크톱에서 캔버스 옆에만 열리고 모바일에서는 그래프 아래에 이어져 선택 프레임을 가리지 않는다.

변경된 페이지와 코드:

- 그래프 화면·배포 마크업: `site/build.mjs`
- 군집·관계 궤도·경로 탐색: `site/assets/knowledge-graph.js`
- 반응형 그래프 UI: `site/assets/site.css`
- 관계 설명·근거 투영: `site/graph/explorer.mjs`
- 정적 결과 검증: `site/verify-build.mjs`
- 단위 테스트: `tests/site-knowledge-graph.test.mjs`
- 작업 기록: [[log]]

### 검증

- 군집 배치, 관계 구역 배치, 최단 경로와 기존 그래프 기능을 포함한 Node 테스트 통과
- 위키 lint·기계적 유지보수 검사·Python 테스트·정적 사이트 빌드·배포 결과 검증 통과
- 데스크톱 브라우저에서 군집 개요의 화면 구조, 11개 주제 군집과 탐색 컨트롤 노출 확인
- 공개 개념 105개·인물 24개와 직접 연결 630개 보존, `raw/` 원본 변경 없음
