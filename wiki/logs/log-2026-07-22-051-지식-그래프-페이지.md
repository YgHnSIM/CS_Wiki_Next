메인 페이지의 `지식 연결망` 캔버스와 문서 목록 패널을 제거하고, 공개 개념·인물 문서만 탐색하는 독립 `지식 그래프` 페이지를 `/map/graph/`에 추가했다. 정규 지식 그래프에서 `concepts`와 `entities` 노드를 투영하고 같은 문서 쌍의 여러 관계를 한 선으로 합쳐, 현재 129개 노드와 630개 직접 연결을 표시한다.

새 그래프는 결정적 force-directed 배치, 빈 공간 이동, 휠 확대·축소, 노드 드래그, 개념·인물 필터, 한글 검색 제안과 선택 문서 패널을 제공한다. 노드를 선택하면 직접 이웃만 밝게 남기는 포커스 표현을 적용했으며, 캔버스를 사용할 수 없는 환경에서도 모든 대상 문서를 찾을 수 있도록 개념·인물 정적 목록을 함께 제공한다. 기존 사이트의 짙은 남보라 바탕, 인광 녹색·호박색, D2Coding·Space Mono와 CRT 질감을 유지했다.

변경된 페이지와 코드:

- 메인·라우팅·빌드: `site/build.mjs`
- 그래프 데이터 투영: `site/graph/explorer.mjs`
- 그래프 상호작용: `site/assets/knowledge-graph.js`
- 그래프·메인 반응형 스타일: `site/assets/site.css`
- 정적 결과 검증: `site/verify-build.mjs`
- 단위 테스트: `tests/site-knowledge-graph.test.mjs`
- 작업 기록: [[log]]

### 검증

- 공개 개념·인물 필터, 중복 관계 집계, 결정적 배치, 검색·카메라 helper 단위 테스트 4개 통과
- 정적 사이트 226개 문서 빌드와 지도 공통 탐색·사이트맵·접근성 fallback 검증 통과
- 실제 브라우저에서 1440×1000 데스크톱과 390×844 모바일 레이아웃, 검색·필터·노드 선택·정보 패널 확인
- 메인 페이지의 구 `지식 연결망` 마크업과 내장 데이터가 제거되고 새 지식 그래프 링크가 노출되는지 확인
- `raw/` 원본 변경 없음
