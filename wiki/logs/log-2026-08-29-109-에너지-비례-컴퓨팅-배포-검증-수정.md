## 문제

`reference: 108_energy_proportional_docs_terms`를 `main`에 푸시한 뒤 GitHub Actions 실행 `33243783715`가 `build / Validate change set` 단계에서 실패했다. `wiki/concepts/에너지 비례 컴퓨팅.md`가 실질적으로 바뀌었지만 `editorial_status: active`인 상태에서 `review.mode: legacy-baseline`을 유지한 것이 원인이었다.

## 수정

- `wiki/concepts/에너지 비례 컴퓨팅.md`의 `review.mode`를 `attested`로 변경했다.
- 검토일을 `2026-08-29`, 검토자를 `codex`로 기록했다.
- 변경된 메타데이터를 포함해 `review.revision`을 다시 계산했다.
- 이 작업 기록을 `wiki/log.md`의 생성 목록에 추가했다.

## 검증

- 같은 `BASE_SHA`를 사용한 `validate_change_set` 로컬 재현이 exit code 0으로 전환됐다.
- `npm run lint:wiki`와 `npm run maintenance:check`를 실행한다.
- 전체 `npm run check`를 실행해 정적 사이트 빌드와 브라우저 검증까지 확인한다.
- 수정 커밋을 푸시한 뒤 GitHub Actions `Deploy CS Wiki`의 `build`와 `deploy` 성공을 확인한다.
