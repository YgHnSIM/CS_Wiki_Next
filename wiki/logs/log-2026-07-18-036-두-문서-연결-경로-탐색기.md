확장 가능한 지식 그래프 UI의 3단계로 임의의 두 공개 문서를 선택해 연결 경로를 설명하는 지식 지도를 추가했다. 최단 선 하나만 그리지 않고 최대 6단계 안에서 기본 경로와 중간 문서가 다른 대안 두 개를 찾는다. 각 단계는 이동 방향, 원래 기록 방향, 대표 관계의 이유와 같은 문서 쌍에 겹친 다른 관계를 세로형 읽기 경로로 번역한다. URL에는 제목이 아니라 안정 그래프 ID와 렌즈·대안 번호를 저장해 새로 고침, 공유, 뒤로 가기에서도 같은 선택을 복원한다.

현재 공개 그래프에서 본문 언급은 전체 관계의 절반가량이고 공통 원전도 지름길 허브가 되기 쉽다. 기본 `핵심 연결` 렌즈는 관련 항목과 학습 순서를 우선하고 자동 본문 언급과 고차수·원전 중간 노드에는 추가 비용을 둔다. `개념·학습`, `근거 계보`, `본문 언급 포함` 렌즈를 분리했으며, 비용이 높은 직접 관계도 대안에서 사라지지 않게 했다. 숨김 운영 문서는 종점과 경유점에서 모두 제외하고, 문맥 전용 문서는 검색 대상에서는 빼되 설명에 필요한 중간 경유점으로 사용할 수 있다.

문서가 늘어날 때 전체 조합을 미리 만들지 않는다. 204개 경유 가능 문서와 3,231개 관계를 페이지 진입 시 한 번만 불러와 인접 색인으로 바꾸고, 이후 요청은 최대 24개 결과를 브라우저에 재사용한다. 경로 계산은 별도 Web Worker에서 수행해 그래프가 커져도 입력과 스크롤을 막지 않으며, Worker를 지원하지 않는 환경에서는 같은 알고리즘으로 안전하게 대체한다. 관계 문맥은 대표 한 건으로 압축하되 간선별 ID·편집 여부·가중치·비용은 보존해 앞으로 `related`나 `supports` 유형을 편집자가 직접 지정해도 우선순위가 사라지지 않는다. 경로 전용 데이터는 전체 그래프보다 작은 약 1.61MB다. 각 문서의 관계 레일과 홈페이지, 전역 메뉴에서 연결 탐색기로 바로 진입할 수 있다.

### 검증

- Node 사이트·그래프·경로 테스트 28개 통과
- 약한 직접 본문 언급보다 의미 있는 다단계 경로 우선, 공통 원전 허브 억제, 직접 관계 보존과 대안 경로 중복 제거 확인
- 현재 전체 데이터에서 인접 색인 약 28ms, 대표 40개 경로 질의 평균 약 86ms·최대 약 250ms 확인; 대안 탐색 전체가 하나의 계산 예산을 공유하며 한도에 닿아도 이미 찾은 기본 경로는 보존
- 기본·개념 렌즈, 대안 선택, 방향키, 문서 교환, 뒤로 가기, 잘못된 URL 정규화와 같은 문서 선택 오류 확인
- Worker 응답을 5초 늦춘 경합 재현에서 계산 중 입력을 바꿔도 이전 결과·주소·복사 상태가 되살아나지 않음을 확인
- 390×844 화면에서 세로 경로와 한 열 선택 폼, 가로 넘침 없음 확인
- 브라우저 콘솔 오류·경고 0건, `raw/` 원본 변경 없음
