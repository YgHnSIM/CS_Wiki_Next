프로젝트 전체 점검에서 확인한 출처 재현성, 내용 정확성, 자동 점검, 상호 링크, 상태 운영, 색인·로그 규칙 문제를 일괄 정리했다. `raw/` 원본은 수정하지 않았다.

주요 변경:

- `AGENTS.md`에 `source_id`, `source_kind`, 직접·보조 근거, URL, 접근일, 판본, 스냅샷 상태와 `draft → review → active` 승격 기준을 추가했다.
- 정규 소스 6개에 `src-001`~`src-006`, 참고 자료 29개에 `ref-001`~`ref-029`를 부여하고 provenance 필드를 정규화했다.
- Unicode UAX #15·#29, UTS #39는 Unicode 17.0.0의 고정 revision URL을 추가하고, WHATWG Encoding은 2026-05-21 commit snapshot을 기록했다.
- 계산 불가능성의 과잉 일반화, 현대 정지 문제와 circle-free 문제의 혼동, 계산기·컴퓨터의 이분법, 프로그래밍 언어 정의, C 시프트·정수 오버플로 설명을 교정했다.
- [[Unicode scalar value]]를 [[코드 포인트]]와 분리해 새 개념 페이지로 만들었다.
- [[초기 소프트웨어의 계층화]]를 EDSAC I 내부 실행 책임과 EDSAC II·Fortran·Unix로 이어지는 후대 연표로 분리했다.
- Cambridge 공식 연구소 역사와 WG14 C 정수 의미론을 정식 참고 자료 페이지로 추가했다.
- 콘텐츠 페이지의 `관련 항목` 역링크 309개를 89개 페이지에 추가하고, 별칭 충돌을 제거했다.
- 짧고 근거 범위가 좁은 개념 5개와 인물 10개를 `draft`로 전환했다.
- [[index]]의 수치를 정규 소스 `(raw 파일 N개)`, 참고 자료 `(핵심 문헌 N개)`, 콘텐츠 `(근거 N개)` 기준으로 통일하고 [[overview]] 통계를 갱신했다.
- [[log]] 항목 내부 제목을 H3로 낮추고 페이지 전역 H2 출처·관련 항목 한 쌍만 남겼으며, Unix와 C / 소프트웨어 재사용 작업의 시간순도 바로잡았다.
- `scripts/wiki_lint.py`와 `scripts/wiki_maintenance.py`를 추가해 검사와 안전한 반복 정리를 자동화했다.
