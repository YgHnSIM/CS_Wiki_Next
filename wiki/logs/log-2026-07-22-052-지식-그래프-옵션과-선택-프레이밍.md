독립 지식 그래프에 Obsidian 전역 그래프 뷰의 설정 범위에 대응하는 옵션 패널을 추가했다. 검색식과 태그·첨부·미생성 파일·고아 노드 필터, 순서와 색상을 지정할 수 있는 그룹, 방향 화살표·텍스트 흐림·노드 크기·연결선 굵기·생성 시점 애니메이션, 중앙·반발·연결·거리 장력과 기본값 복원을 제공한다. 태그, 첨부와 미생성 파일은 문서 메타데이터에서 보조 노드로 구성하며, 문서 사이에 합쳐진 연결도 원래 방향과 관계별 발생 횟수를 보존한다.

노드 선택 경로를 캔버스 클릭, 검색 제안, 키보드와 선택 정보 패널에서 하나로 통합했다. 선택된 문서는 그래프 캔버스의 정확한 중앙에 놓고, 필터 상태와 관계없이 모든 직접 연결 문서를 대칭 안전 프레임 안에 자동으로 맞춘다. 화면 크기나 장력 설정이 바뀌어도 선택 프레임을 다시 계산하며, 사용자가 직접 이동·확대하면 자동 프레이밍을 해제한다. 장력 재계산은 별도 Worker에서 실행하고 실패할 때는 결정적 동기 배치로 복구한다.

변경된 페이지와 코드:

- 그래프 데이터·메타데이터: `site/graph/model.mjs`, `site/graph/explorer.mjs`
- 그래프 상호작용·비동기 배치: `site/assets/knowledge-graph.js`, `site/assets/knowledge-graph-worker.js`
- 옵션 패널·반응형 스타일: `site/build.mjs`, `site/assets/site.css`
- 정적 결과 검증: `site/verify-build.mjs`
- 단위 테스트: `tests/site-graph.test.mjs`, `tests/site-knowledge-graph.test.mjs`
- 작업 기록: [[log]]

### 검증

- 지식 그래프 데이터·옵션·검색식·첨부 경로·장력·카메라 관련 Node 테스트 21개 통과
- 실제 캔버스 클릭에서 선택 노드 중심 오차 0.2px 이하, 선택 노드와 직접 이웃 8개 모두 프레임 안에 표시 확인
- 직접 연결 19개인 문서를 1440×1000 데스크톱과 390×844 모바일에서 선택해 모든 20개 초점 노드가 프레임 안에 표시되는지 확인
- 모바일 하단 설정 시트, 검색 제안과 설정 버튼의 비중첩, 필터·그룹·화살표·장력·기본값 복원·애니메이션·Worker 요청 확인
- 인물 필터에서 선택 보장으로 34개가 표시된 상태로 타임랩스를 시작·중지하면 필터 본래 집합 24개로 정확히 복원되는지 확인
- Obsidian 지원 첨부 형식 전체와 하위 경로 배포용 첨부 주소, URL 없는 보조 노드의 비활성 문서 링크 확인
- 브라우저 콘솔 오류와 경고 0건, `raw/` 원본 변경 없음
