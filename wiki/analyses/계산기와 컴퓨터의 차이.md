## 핵심 비교

[[계산기와 컴퓨터의 차이]]는 모든 시대와 제품에 적용되는 날카로운 이론적 경계라기보다 장치의 설계 목적·프로그램 가능성·제어 구조를 비교하는 역사적·구조적 구분이다. [[차분 기관]]은 특정 계산을 자동화하도록 설계된 장치의 성격을, [[해석 기관]]은 명령을 바꾸어 여러 절차를 수행하려 한 범용 기계의 성격을 보여준다. 이 구도는 20세기 전자식 저장 프로그램 컴퓨터의 태동을 거쳐, 21세기 AI 가속기(TPU/ASIC vs GPU)와 에이전틱 AI 오케스트레이션(CPU)의 이종 분업 구조로 끊임없이 변주되며 재현되고 있다.

| 구분 | 전형적인 특수 목적 계산 장치 (계산기 / DSA / ASIC) | 프로그래머블 병렬 가속기 (GPU) | 전형적인 범용 프로그램 가능 컴퓨터 (해석 기관 / CPU) |
|---|---|---|---|
| 설계 목적 | 정해진 연산 패턴(다항식 차분, 행렬 곱셈)의 속도·효율 극대화 | 대규모 데이터 병렬 처리(SIMT) 및 가속 | 서로 다른 종류의 임의 절차, 분기, 기호 조작 실행 |
| 동작 변경 | 회로/기구 고정, 제한된 파라미터 구성 | 프로그램 가능한 셰이더·커널 교체 | 저장된 명령어나 소프트웨어 스택 교체 |
| 제어 구조 | 고정된 데이터플로우 / 시스톨릭 파이프라인 | 워프 스케줄러 기반 대규모 병렬 제어 | 순서, 조건 분기, 반복, 절차 호출, 인터럽트, OS 오케스트레이션 |
| 표현 대상 | 특정 형식의 수치(정수, 부동소수점, 저비트 텐서) | 대규모 다차원 배열, 벡터, 텐서 | 명시된 표현 규칙에 따른 수치·기호·텍스트·데이터 구조 |
| 역사적 원형 | [[차분 기관]], 탁상 계산기 | 벡터 프로세서, 그래픽 파이프라인 | [[해석 기관]], [[EDSAC]], [[EDVAC]] |
| 현대 AI 대응 | [[In-Datacenter Performance Analysis of a Tensor Processing Unit|Google TPU]], 전용 NPU, 추론 ASIC | NVIDIA Hopper/Blackwell, AMD Instinct | [[A New Golden Age for Computer Architecture|호스트 CPU]] (AMD EPYC, Grace CPU) |

현대의 공학용 계산기처럼 프로그램 기능을 갖춘 계산기도 있고 컴퓨터도 특정 용도에 내장될 수 있다. 따라서 제품 이름만으로 분류하기보다 어느 정도까지 동작을 기술하고 바꿀 수 있는지, 장치가 어떤 사용 범위를 목표로 하는지를 함께 보아야 한다.

## 배비지 사례의 의미

차분 기관은 [[수학 표|다항식 표]]를 계산하고 인쇄하기 위해 설계된 특수 목적 장치다. 반면 해석 기관은 Mill과 Store, 천공 카드, 반복, 조건 분기를 포함함으로써 명령에 따라 다른 작업을 수행할 수 있는 구조를 지향했다. 이 차이가 계산 자동화에서 범용 컴퓨팅으로 넘어가는 개념적 전환이다.

## 러브레이스의 확장

[[에이다 러브레이스]]는 해석 기관을 단순한 수치 계산 장치로 보지 않았다. Note A에서 "자카드 직조기가 꽃과 잎을 짜듯, 해석 기관은 대수적 패턴을 짠다"고 갈파했듯, 연산(Mill)과 저장(Store)의 분리 위에 천공 카드로 제어 흐름을 지휘하는 구조는 숫자가 관계나 의미를 표현할 수 있다면 기계가 음악이나 도형 같은 비수치적 기호 체계도 처리할 수 있음을 의미했다. 이 해석은 컴퓨터를 고정된 계산기에서 연산·저장·제어를 직조하는 범용 [[하드웨어 실행 모델]]로 확장하는 결정적 전환점이다.

## EDSAC의 실용적 전환

[[EDSAC]]은 이 차이를 20세기 전자식 저장 프로그램 컴퓨터의 실용 환경에서 다시 보여준다. 핵심은 프로그램이 기계의 고정 배선이 아니라 메모리에 저장되고 적재되며, 다른 절차에 의해 해석될 수 있는 대상이 되었다는 점이다. [[Initial Orders]], [[부트스트랩]], [[디버깅]], [[서브루틴]], [[라이브러리]]는 컴퓨터가 단순 계산 장치를 넘어 소프트웨어 계층을 실행하는 플랫폼으로 바뀌었음을 보여준다.

[[EDVAC]]과 [[Manchester Baby]]는 이 전환의 다른 기준을 보충한다. EDVAC은 저장 프로그램 컴퓨터의 논리 구조를 설계 문서로 정식화했고, Baby는 저장 프로그램을 실제 전자식 기계에서 실행했다. EDSAC은 그 원리가 실용적 계산 서비스와 프로그램 작성 문화로 연결될 수 있음을 보여준다.

이 계보에서 중요한 전환은 장치가 수행할 산술을 하나씩 추가한 것이 아니라 프로그램을 바꾸어 여러 작업을 기술하고 실행하는 구조를 확장한 데 있다. 다만 이를 두 제품 범주의 [[계산 가능성]]이 본질적으로 다르다는 주장으로 확대해서는 안 된다. 제한된 계산기라도 특정 범위의 프로그램 기능을 가질 수 있고 실제 컴퓨터도 유한한 메모리와 시간의 제약을 받는다.

## 현대의 차분 기관: 도메인 특화 아키텍처(DSA)와 AI ASIC

21세기 인공지능 혁명은 특수 목적 계산기의 원리를 첨단 반도체 위에 다시 불러냈다. [[A New Golden Age for Computer Architecture|존 헤네시와 데이비드 패터슨이 진단]]했듯, [[무어의 법칙]]과 [[Dennard 스케일링]]이 둔화되면서 단일 범용 프로세서의 성능 향상은 물리적 한계에 직면했다. 이에 대한 해법으로 등장한 **도메인 특화 아키텍처**(DSA, Domain-Specific Architectures)는 심층 신경망의 수학적 본질인 범용 행렬 곱셈(GEMM)에 하드웨어 자원을 극단적으로 집중했다.

[[In-Datacenter Performance Analysis of a Tensor Processing Unit|Google TPU]]나 각종 신경망 가속 ASIC은 배비지가 다항식 계산을 위해 기어의 물리적 맞물림을 고정했던 것처럼, 행렬 연산 데이터플로우를 처리하는 **시스톨릭 어레이(Systolic Array)** 회로를 실리콘에 고정했다. 범용 CPU가 갖추어야 하는 복잡한 분기 예측기, 비순차 명령어 실행(Out-of-Order Execution) 로직, 다단계 캐시 일관성 유지 회로를 과감히 제거함으로써, 이들 전용 칩은 전력 1와트당 처리할 수 있는 연산 횟수(TOPS/W)를 수십 배 이상 끌어올렸다. 즉, 가장 현대적인 AI 하드웨어의 한 축은 역설적으로 "고정된 수치 연산을 가장 효율적으로 수행하는 초고속 계산기"의 형태로 회귀한 것이다.

## 병렬 범용성의 진화: GPU와 프로그래머블 플랫폼

ASIC이 특수 목적 계산기의 극단을 대표한다면, **GPU**(Graphics Processing Unit)는 범용성과 특화 사이의 절묘한 균형점을 보여준다. 초기의 GPU는 3차원 기하 변환과 래스터화만을 담당하던 그래픽 전용 파이프라인(계산기)이었으나, 프로그래머블 셰이더와 [[Scalable Parallel Programming with CUDA|CUDA]]의 등장을 통해 대규모 데이터 병렬 처리(SIMT)를 수행하는 범용 연산 플랫폼으로 진화했다.

인공지능 모델의 지배적 아키텍처가 합성곱 신경망(CNN)에서 순환 신경망(RNN), 트랜스포머(Transformer), 확산 모델(Diffusion), 전문가 혼합(MoE)으로 끊임없이 변모하는 동안 GPU가 핵심 가속기로 군림할 수 있었던 이유는 바로 이 **프로그램 가능성**(Programmability)에 있다. 알고리즘이 바뀔 때마다 실리콘을 새로 제조해야 하는 전용 ASIC과 달리, GPU는 소프트웨어 커널과 프레임워크 갱신만으로 새로운 계산 절차를 즉각 수용했다. 이는 에이다 러브레이스가 통찰했던 "하드웨어 변경 없는 소프트웨어적 직조"가 병렬 연산 영역에서 구현된 사례다.

## 에이전틱 AI와 현대판 해석 기관: 제어·오케스트레이션과 CPU의 재부각

최근 인공지능 패러다임이 단순한 토큰 일괄 생성(단순 연산)에서 자율적으로 추론하고 행동하는 **에이전틱 AI**(Agentic AI)로 전환되면서, 시스템의 무게중심은 다시 범용 프로세서인 **CPU**로 이동하고 있다. 

에이전틱 AI 워크로드는 대규모 행렬곱뿐 아니라 다음과 같은 복잡한 제어 작업을 연속적으로 수행한다:
- **다단계 계획 및 추론 분기**: 작업 목표를 하위 태스크로 분해하고 결과에 따라 실행 경로를 동적으로 결정.
- **도구 호출(Tool Calling) 및 외부 연동**: API 요청, SQL 데이터베이스 질의, 외부 샌드박스 코드 실행.
- **불규칙한 상태 및 메모리 관리**: 대규모 KV 캐시 스케줄링, 벡터 검색(RAG), 동적 컨텍스트 윈도우 조작.

이러한 작업은 행렬곱에 특화된 가속기(계산기)로는 효율적으로 처리하기 어렵고, 고도의 분기 예측, 빠른 단일 스레드 응답성, 거대한 시스템 메모리 대역폭을 갖춘 CPU가 전담해야 한다. AMD EPYC(Zen 5 Turin, Zen 6 Venice)를 비롯한 고성능 서버 CPU가 AI 인프라에서 GPU와 1:1에 가까운 비율로 배치되거나 독자적인 추론 오케스트레이션 호스트로 급부상하는 현상은, 러브레이스가 해석 기관에서 발견했던 "수치 계산(Mill)을 넘어선 기호 조작과 제어 오케스트레이션"의 가치가 현대 AI 데이터센터에서 재입증된 것이다.

## 진자 운동으로서의 컴퓨팅 역사: 특화와 범용의 나선형 공존

컴퓨팅 역사는 특수 목적 계산기가 범용 컴퓨터로 완전히 대체되고 끝난 단선적 과정이 아니다. 기술의 병목과 경제성에 따라 진자처럼 왕복하는 나선형 발전이다:

1. **기계식 시대**: 특수 목적 차분 기관의 한계에서 범용 해석 기관의 설계 사상이 탄생함.
2. **전자식 초기**: 고정 배선식 전용 계산 회로에서 메모리 저장 프로그램 범용 컴퓨터(EDSAC)로 도약함.
3. **반도체 집적기**: 단일 범용 CPU가 모든 연산을 지배하며 무어의 법칙을 구가함.
4. **전력 장벽과 AI 시대**: 범용 CPU의 한계로 인해 전용 연산기(ASIC/TPU)와 병렬 가속기(GPU)로 특화됨.
5. **에이전틱 AI와 이종 컴퓨팅**: 초특화 연산기(현대판 차분 기관)와 범용 제어 프로세서(현대판 해석 기관)가 긴밀하게 결합된 **[[이기종 실행 모델]]**로 수렴함.

결국 현대의 컴퓨터 시스템은 계산기와 컴퓨터 중 하나를 택하는 것이 아니라, “**수치 연산의 가속은 특화된 계산기(ASIC/GPU)에 맡기고, 시스템의 기호 조작과 제어 흐름은 범용 컴퓨터(CPU)가 지휘한다**”는 분업의 완성을 지향하고 있다.

- [[도메인 특화 가속기]] — 특정 연산 패턴에 하드웨어를 고정해 효율을 얻는 현대판 특수 목적 계산기.
- [[이기종 실행 모델]] — CPU 호스트와 가속기가 제어와 연산을 분담하는 실행 구조.
- [[해석 기관]] — Mill, Store, 천공 카드, 반복, 조건 분기를 포함한 범용 기계식 계산 장치 설계.
- [[하드웨어 실행 모델]] — 연산(ALU)·저장(RAM)·제어(PC)의 3축 분리와 버스 분업 위에서 명령 사이클을 회전시키는 물리적 컴퓨터 동작 구조.
- [[범용성은 어떻게 컴퓨팅 능력이 되었는가]] — 특수 목적 장치에서 저장 프로그램, 컴파일러로 확장된 범용성의 역사.
