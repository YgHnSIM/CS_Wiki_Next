## 개요

[[해석기하학]](Analytic Geometry, Coordinate Geometry)은 수치 좌표(Coordinates)를 매개로 기하학적 도형(형태)과 대수학적 방정식(기호) 사이에 1:1 전단사 번역기를 수립하여, 공간의 형태 문제를 대수적 계산과 방정식 풀이로 치환하는 수학 체계다.

17세기 전반 르네 데카르트(René Descartes)와 피에르 드 페르마(Pierre de Fermat)에 의해 독립적으로 창안되었다. 고대 그리스 이래 시각적 작도에 갇혀 있던 기하학을 대수적 계산으로 변환함으로써, 미적분학의 모태가 되었으며 오늘날 컴퓨터 그래픽스, GPU 래스터화, GIS 지리정보시스템의 근본 기초를 제공한다.

## 메커니즘: 형태와 식의 1:1 대응

해석기하학의 핵심은 평면 위의 모든 점에 수치 순서쌍 $(x, y)$라는 고유한 '신분증(주소)'을 부여하는 것이다.

```text
       기하학 (형태)                     해석기하학                     대수학 (방정식)
[ 시각적 공간의 궤적 ]  <===========>  [ 좌표계 번역기 ]  <===========>  [ 미지수 x, y 관계식 ]
  - 직선 (Straight Line)                 (x, y) 좌표                ax + by + c = 0
  - 원 / 타원 / 포물선                                              Ax² + Bxy + Cy² + ... = 0
  - 고차 루프 곡선                                                  f(x, y) = 0
```

1. **하향식 번역 (데카르트: 기하 $\to$ 대수)**: 곡선 위의 임의의 점 $P$가 만족해야 하는 기하학적 거리 비례 조건을 대수적 다항식 관계로 변환한다 (파푸스 문제의 해법).
2. **상향식 번역 (페르마: 대수 $\to$ 기하)**: 두 미지수 사이의 관계를 만족하는 점 $(x, y)$의 자취를 평면 위에 그려냄으로써 미지의 곡선을 시각화한다.

곡선 위의 모든 점은 오직 그 곡선의 방정식만을 오차 없이 만족하며, 곡선 밖의 점은 만족하지 않는다. 즉, **방정식 자체가 다른 언어로 표현된 곡선 그 자체**가 된다.

## 역사적 진화와 현대 컴퓨터 과학으로의 확장

1. **직교 좌표계의 정착**: 데카르트 원전의 사교좌표계와 단일 축에서 출발하여, 판 스호텐, 존 월리스, 라이프니츠를 거치며 오늘날의 직교 모눈종이 체계로 완성되었다.
2. **GPU와 디스플레이 래스터화**: 현대 스마트폰과 모니터의 수백만 픽셀은 2D 직교 좌표 평면으로 모델링되며, GPU는 메모리 주소 변환 공식 `Addr = (y * Stride + x) * BPP`를 통해 기하학적 도형을 하드웨어 버퍼에 구워낸다.
3. **모바일 물리 엔진과 지도 투영**: 터치스크린 관성 스크롤의 뉴턴 감쇠 미분방정식($m\ddot{x} + c\dot{x} = 0$) 적분과, GPS 기반의 Web Mercator(EPSG:3857) 지도 핀 앵커링 공식은 모두 해석기하학적 좌표 번역 체계 위에서 실시간으로 연산된다.
