## 개요

[[그래핌 클러스터]]는 사용자가 문자 하나로 인식하는 단위에 대한 프로그램 가능한 근사다. Unicode Text Segmentation은 extended grapheme cluster를 기본 모델로 제공하며 텍스트 선택, 커서 이동, 삭제, 문자 수 제한, 정규식 처리에서 중요하다.

## 코드 포인트와의 차이

하나의 [[코드 포인트]]가 항상 사용자가 보는 문자 하나인 것은 아니다. 기본 문자와 결합 부호, 한글 자모 시퀀스, 일부 인도계 문자, 이모지 ZWJ sequence는 여러 코드 포인트가 합쳐져 하나의 그래핌 클러스터를 이룰 수 있다.

반대로 코드 유닛 수는 더 낮은 저장 단위다. 예를 들어 [[UTF-16]]에서는 하나의 [[Unicode scalar value]]가 surrogate pair인 두 [[코드 유닛]]으로 표현될 수 있고 그 scalar value가 다시 다른 코드 포인트와 결합해 하나의 그래핌 클러스터를 이룰 수 있다.

## 실무적 의미

사용자에게 보이는 "글자 수" 제한을 만들 때 바이트 수나 코드 유닛 수만 세면 예기치 않은 결과가 생긴다. 텍스트 편집기에서 Backspace 한 번으로 무엇을 지워야 하는지, UI에서 커서가 어디에 놓여야 하는지, 검색에서 한 글자를 어떻게 매칭할지도 그래핌 클러스터 경계와 연결된다.

## 관련 항목

- [[유니코드]] — 다양한 문자와 기호를 코드 포인트, 인코딩 형식, 정규화, 텍스트 경계 문제로 포괄하는 문자 체계.
- [[코드 포인트]] — Unicode 문자 공간에서 특정 위치를 가리키는 숫자 값과 scalar value의 구분을 정리한 개념.
- [[Unicode scalar value]] — Unicode 코드 포인트 가운데 surrogate 영역을 제외해 UTF 인코딩 형식의 입력이 되는 값.
- [[코드 유닛]] — UTF-8, UTF-16 같은 인코딩 형식이 문자열을 저장·전송할 때 사용하는 최소 단위.
- [[UTF-8]] — Unicode scalar value를 1-4개의 8비트 코드 유닛으로 표현하는 ASCII 호환 가변 길이 인코딩.
