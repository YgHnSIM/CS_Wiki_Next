## 개요

[[해석 기관]](Analytical Engine)은 [[찰스 배비지]]가 설계한 미완성 기계식 범용 계산 장치다. [[차분 기관]]이 특정 [[수학 표]] 계산을 위한 특수 목적 기계였다면, 해석 기관은 명령에 따라 여러 절차를 수행할 수 있는 범용 기계를 지향했다.

## 구조

| 해석 기관 요소 | 현대적 대응 | 실행 모델의 축 |
|---|---|---|
| Mill | 중앙처리장치 또는 연산 장치(ALU) | **연산 축** (씨실) |
| Store | 메모리 또는 저장 장치(RAM) | **저장 축** (날실) |
| 연산 카드 / 변수 카드 | 명령어와 데이터 주소 지정 | **제어 축** (바늘 / 북) |
| 자카드식 천공 카드 | 프로그램 입력 매체 | 제어 입력 |
| 반복과 조건 분기 | 제어 흐름 | 제어 흐름 |

## 역사적 의미

해석 기관은 물리적으로는 톱니바퀴와 천공 카드에 기반한 19세기 기계였지만, 논리적으로는 현대 [[하드웨어 실행 모델]]의 핵심 3축 구조를 예고했다. [[에이다 러브레이스]]는 자카드 직조기가 직물의 무늬를 짜듯 해석 기관이 대수적 패턴을 짠다고 비유했다. 이는 Mill(연산)과 Store(저장)의 물리적 분리 위에 천공 카드의 순서가 실행 흐름을 지휘하는 구조적 실행 원리를 꿰뚫어 본 통찰이었다.

다만 이 기계는 완성되지 않았기 때문에 현대 전자식 컴퓨터의 직접 조상이라기보다 범용 프로그램 가능성의 개념적 선구로 이해하는 편이 정확하다.

## 관련 항목

- [[수학 표]] — 반복해서 필요한 함수와 계산의 결과를 미리 구해 저장·배포한 참조 도구로, 서로 다른 역사적 맥락에서 나타난 고대 면적표, 근대 로그·천문표와 배비지의 표 제작 자동화를 함께 설명한다.
- [[찰스 배비지]] — 차분 기관과 해석 기관을 설계해 계산 자동화와 범용 컴퓨팅 개념을 제시한 19세기 수학자·발명가.
- [[에이다 러브레이스]] — 해석 기관의 의미를 해석하고 Note G를 통해 알고리즘과 기호 조작 가능성을 설명한 수학자.
- [[하드웨어 실행 모델]] — 연산(ALU)·저장(RAM)·제어(PC)의 3축 분리와 버스 분업 위에서 명령 사이클을 회전시키는 물리적 컴퓨터 동작 구조.
- [[알고리즘적 사고]] — 문제를 단계, 데이터, 반복, 조건, 관찰, 재사용 가능한 단위로 분해해 기계가 수행할 수 있게 만드는 사고방식.
