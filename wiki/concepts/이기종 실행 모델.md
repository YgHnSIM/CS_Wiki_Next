## 개요

[[이기종 실행 모델]]은 하나의 계산을 CPU, GPU, FPGA 기반 장치, 행렬 가속기처럼 구조가 다른 실행 대상에 나누어 배치하는 규칙과 인터페이스다. 여기에는 어떤 계산을 대상 장치에서 실행할지, 작업을 어떤 병렬 단위로 나눌지, 입력·중간값·출력을 어느 메모리 공간에 둘지, 결과가 언제 호스트나 다른 작업에 보이는지가 포함된다.

[[Scalable Parallel Programming with CUDA|CUDA]]는 호스트와 커널, 스레드·블록·그리드, 여러 메모리 공간을 구분해 GPU의 대량 병렬성을 프로그램 구조에 드러낸 사례다. [[TVM - An Automated End-to-End Optimizing Compiler for Deep Learning|TVM]]은 계산 그래프와 연산자 코드를 CPU·GPU·가속기 백엔드로 내리며, 대상마다 달라지는 연산 원시 기능과 메모리 계층을 컴파일 단계에서 다룬다.

## 실행 모델이 정하는 것

이기종 실행 모델은 단지 함수 호출의 목적지를 바꾸는 장치가 아니다. 다음 선택이 서로 맞아야 한다.

- 계산 분할: 어떤 연산을 장치로 보내고 어떤 연산을 호스트에 남길지 정한다.
- 병렬 배치: 작업을 스레드, 블록, 벡터, 타일 또는 장치별 큐에 어떻게 나눌지 정한다.
- 데이터 이동: 입력·가중치·중간값의 복사, 재사용, 배치와 메모리 공간을 정한다.
- 동기화와 완료: 의존 작업이 언제 시작할 수 있고 결과가 어느 경계에서 관찰되는지 정한다.
- 배포: 생성 코드, 라이브러리, 드라이버와 런타임이 어느 대상 조합에서 함께 동작하는지 정한다.

각 선택은 작업량, 입력 형태, 메모리 용량, 통신 비용과 장치 세대에 따라 달라진다. 따라서 가속기를 호출할 수 있다는 사실은 그 가속기의 연산기와 메모리 대역폭을 실제 작업에서 충분히 사용한다는 보장이 아니다.
